Agentic Support Copilot — Enterprise RAG & Distributed AI System

Python FastAPI LangGraph Qdrant Redis Cohere Rerank Docker AWS EC2 React TypeScript
  • Enterprise Agentic RAG Architecture: Engineered an enterprise Agentic RAG copilot using FastAPI, LangGraph, and Qdrant to automate technical documentation support with verifiable per-sentence source citations and zero hallucinations.
  • Hybrid Search & RRF Decomposition: Implemented Reciprocal Rank Fusion (RRF) and sub-query decomposition, resolving complex multi-topic customer queries and elevating Context Recall to 100% (1.00) and Answer Correctness to 85.3% on a 55-question golden benchmark.

SafeChat — Real-Time Multilingual Toxic Chat Moderation & Detoxification System
GitHub ↗ Live Demo ↗
PyTorch Hugging Face LoRA / PEFT FastAPI Gemini 2.5 Docker WebSockets AWS EC2
  • Architected a Dual-Tier Hybrid Moderation Pipeline: Engineered a real-time moderation engine combining a sub-50ms edge transformer classifier with a foundational LLM arbitrator for high-throughput live chat rooms.
  • Domain Adaptation with LoRA: Fine-tuned hing-roberta on code-mixed Hinglish and Devanagari Hindi using Parameter-Efficient Fine-Tuning (LoRA), slashing trainable parameters by 98.2% while achieving a 0.7154 Macro F1 and 0.9451 ROC-AUC.

  • Hardened Cloud Deployment on AWS EC2: Containerized the full-stack system using Docker and FastAPI, orchestrating real-time bidirectional WebSockets reverse-proxied with Caddy automated TLS/SSL.
